## 🚀 خطوات التشغيل

### 1. تثبيت Node.js

**Windows:**
1. اذهب إلى [nodejs.org](https://nodejs.org)
2. حمل النسخة LTS (الموصى بها)
3. ثبتها بالطريقة العادية

**Mac:**
```bash
brew install node
```

**Linux (Ubuntu/Debian):**
```bash
sudo apt update
sudo apt install nodejs npm
```

### 2. تثبيت المشروع

```bash
# 1. افتح Terminal/Command Prompt
# 2. انتقل لمجلد المشروع
cd naa-academy

# 3. ثبت التبعيات
npm install

# 4. شغّل الخادم
npm start
```

### 3. فتح الموقع

افتح المتصفح واذهب إلى:
```
http://localhost:3000
```

أو افتح ملف `index.html` مباشرة (يتواصل مع الخادم تلقائياً).

## 📊 هيكل قاعدة البيانات

### الجداول:

| الجدول | الوصف |
|--------|-------|
| `users` | المستخدمين (لاعبين + مدربين + مدير) |
| `coaches` | معلومات إضافية للمدربين |
| `permissions` | صلاحيات المدربين |
| `registrations` | طلبات الانضمام |
| `approved_players` | اللاعبين المقبولين |
| `nominees` | مرشحو التصويت |
| `votes` | الأصوات |
| `weekly_stars` | نجوم الأسبوع |
| `media_photos` | الصور |
| `media_videos` | الفيديوهات |
| `results` | نتائج المباريات |

### العلاقات:
```
users (1) ──────► coaches (1) ──────► permissions (1)
   │
   ├──► registrations (N) ──────► approved_players (1)
   │
   ├──► votes (N)
   │
   ├──► weekly_stars (N)
   │
   ├──► media_photos (N)
   │
   └──► media_videos (N)

nominees (1) ◄────── votes (N)
```

## 🔄 عمليات CRUD

### إضافة (Create):
```javascript
// مثال: إضافة نتيجة
await api('/results', {
  method: 'POST',
  body: JSON.stringify({
    match_date: '2026-06-08',
    match_name: 'أشبال الجديدة vs فريق X',
    score: '3-1',
    note: 'فوز مستحق'
  })
});
```

### قراءة (Read):
```javascript
// مثال: جلب النتائج
const results = await api('/results');
```

### تعديل (Update):
```javascript
// مثال: تثبيت فيديو
await api('/media/videos/1/pin', {
  method: 'PATCH',
  body: JSON.stringify({ is_pinned: true })
});
```

### حذف (Delete):
```javascript
// مثال: حذف لاعب مقبول
await api('/approved-players/1', { method: 'DELETE' });
```

## 🔄 الترقية المستقبلية

للترقية إلى MySQL/PostgreSQL في المستقبل:
1. غيّر `database.js` ليستخدم `mysql2` أو `pg`
2. حدّث الاستعلامات لتتوافق مع قاعدة البيانات الجديدة
3. بقية الكود يبقى كما هو!

## 🆘 الدعم
